# The Crochet Center

Responsive pink and lavender boutique website template.

## Run locally

Run `npm start`, then open http://127.0.0.1:5173. No dependencies are needed. Run `npm run check` for JavaScript syntax validation.

## Customize

Edit product data in `assets/app.js`, styles in `assets/styles.css`, and page sections in `index.html`. Replace illustrated sample products and prices with approved client content before launch.

Favorites and the preview bag persist in browser local storage. Custom requests and checkout are demonstrations; they do not submit orders or accept payments.

## Design references

Layout research: https://www.gococoon.store/ and https://saracrochet.in/. Original illustrations; no copied product photographs.
